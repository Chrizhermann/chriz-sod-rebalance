# v0.6.11 — Skie and Khalid bridge compatibility

Release dated September 16, 2026. This fixes component **197** failing to install
after Khalid continuity **115**, including installations with the bridge overhaul
**256** already present. Component numbers, encounter balance and rewards are
unchanged; the installer still exposes **42 declarations in seven groups**.

## Changed behavior

Skie's component formerly expected two obsolete bridge spawns. Component 115
forks the original victories into carried-Khalid and ordinary routes; component 256
can consolidate the two victory conditions. The updated recognizer validates
those actual structures before removing only Skie's creation actions:

| Installed bridge layout | Expected victory blocks and Skie spawns |
| --- | --- |
| Original | Two native victories |
| 115 | Four blocks: two matching carried/ordinary pairs |
| 256 | One consolidated victory |
| 115 and 256 | One matching carried/ordinary pair |

Khalid's route guards, carried-party retreat protection, additional installed
conditions and other victory actions remain intact. Incomplete forks, mismatched
payloads and unexpected extra spawns still fail rather than accepting a count alone.

When 197 is installed after 256, its older Bence dialogue starter now defers while
256's wrap is pending. The bridge overhaul retains its combat/dialogue checks
and retry behavior in either order.
