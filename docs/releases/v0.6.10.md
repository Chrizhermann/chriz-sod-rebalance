# v0.6.10 — Khalid's Bridgefort continuity

Release dated September 14, 2026. The user accepted the corrected entry and
briefing and explicitly authorized shipping this fix.

Component **115** keeps a carried Khalid controllable when entering Bridgefort.
Both native recruiter blocks are protected directly, including when an arriving
actor is not yet found by the ordinary named lookup. Adirran supplies the fort's
briefing and command choices. The original commander route remains available
when Khalid was not carried. Conditional dialogue, journals and scene handling
preserve his personal quest and remove conflicting separation references.

Components **115** and **256** support either installation order. Both preserve
the bridge victory conditions and Bence's prompt arrival; the carried-Khalid
aftermath omits the native NPC retreat assignments.

## Install

Close the game, extract the Windows package into its directory, and run
`setup-chriz-sod-remix.exe`. Component **110** is required. Append **115** without
uninstalling earlier components. Install before first visiting BD2000, ideally
before SoD starts so the earlier companion-history dialogue also applies.

If Khalid was already moved and neutralized by the original recruiter setup,
reload a save from before that visit. This component prevents the reset; it does
not rewrite an already-damaged saved companion or replay completed scenes.

The TP2 exposes **42 declarations in seven groups**. Other component numbers,
bridge difficulty and optional sequencers are unchanged.
