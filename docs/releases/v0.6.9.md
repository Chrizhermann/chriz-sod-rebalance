# v0.6.9 release

Release dated September 13, 2026. The user authorized merging, tagging and
publishing the tested scope recorded here.

## Included

- **256:** replace the Boareskyr barrel/portal finale with two mages, two
  veteran guards and four fire/earth elementals. Keep finite defenses,
  difficulty scaling and elemental-targeted Haste on enemy sighting.
  Bence appears beside the party after combat and opens passage through his
  existing dialogue. Remove obsolete mechanics, text and day/night barrel art.
- **257, optional Extra Challenge:** add only the two Insane sequencers.
  Fire uses Dispel Magic with Spell Revisions, Remove Magic otherwise, then
  Flame Arrow. Earth uses Greater Malison then Slow. The default has the same
  stats, spellbooks, Haste and other AI without sequencer use.
- **266, default:** Shadow Aspect can use Insane Mislead once per actor;
  repeated casting is blocked. Its other invisibility and AI remain.
- **135, default:** retain the assassin ambush, remove dead magic and the
  misleading descriptions. **235/265:** preserve Ymori, restore Mizhena's
  amulet on the approved corpse, and complete the approved creature removals.
- **175/176:** Liia's reward is 22,000 XP per character on every difficulty.
  Keep the corrected road-north and coalition quest compensation.
- Correct restored Skie's protagonist-dependent XP catch-up, condolence and
  rejoin dialogue, and locked SCS potions. Preserve the verified Xan/Yeslick
  aliases and Shar-Teel's field rejoin route.

The TP2 exposes **41 declarations in seven groups**. Existing component numbers
remain stable. Select 257 only for Extra Challenge; it requires the current
256 resources. This version includes no collapse timer, cleric or extra mages.

## Verification

Current source passed with WeiDU 249:

- 273 main regression tests, including 101 bridge checks and 13 Mislead checks.
- 41 research/tooling tests and 14 ending contract self-tests.
- Parse checks for the public TP2 and all 56 installer libraries.
- Three packaged-installer checks for regular bridge AI, optional sequencers
  and the public Mislead correction, including disposable restoration.

The public installer tests prove that the default and challenge mage scripts
differ only by the sequencer blocks, with Haste retained in both. Component257
changes exactly the two Insane CRE script pointers, and its disposable-fixture
uninstall restores the prior resources exactly. The Mislead tests use a captured
native binary block and verify the public entry, preservation, repeat application,
rejection of changed scripts and restoration. These are offline installer/script
checks, not additional native combat tests.

The user accepted the stronger bridge combat, prompt Bence arrival, save/reload
and onward crossing. Assassin spellcasting/buff persistence and the Guardian's
inactive state were also observed. The final component split and Mislead cap
have not received a new native run. Shadow Aspect's unfinished summon check is
deferred and explicitly does not block this release. The recurring companion
equipment appearance problem remains unresolved.

See the [combined playtest](../playtest/2026-09-09-fast-sod-test-plan.md) and
[Shadow Aspect record](../playtest/2026-09-13-shadow-aspect-resume.md).

## Installation and release boundaries

Close the game before installing and retain existing WeiDU history. Append
new components whose prerequisites are present; do not reinstall earlier rows.
Updated source for already-installed110/197 does not repair an existing install
merely by replacing the archive. Those fresh-install corrections were separately
tail-patched in the isolated playtest copy; that local repair is not a public
upgrade component in this release.

Use a save from before the first BD2000 visit for256, and before the encounter
spawns for257. BD5000/BD5110 area changes need uncached areas. Already-paid XP
is not deducted. No test-game or live-game installation was made during this
release preparation.

The Windows release includes matching root/nested TP2 files, WeiDU249 and its
license, third-party notices, component inventory and this validation record.
The package is accompanied by a SHA256 checksum and per-file contents manifest.
The annotated v0.6.9 tag identifies the source used for the Windows package.
The existing worktrees and test saves are retained; release publication does
not imply that unrelated local work was cleaned up or a game was updated.
