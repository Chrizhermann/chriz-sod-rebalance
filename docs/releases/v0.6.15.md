# v0.6.15 — Bridge finale alongside Tweaks Anthology's summon fog

Released October 23, 2026. It fixes one installation conflict of component 256 on
top of v0.6.14. The installer still exposes **49 declarations in seven groups**.

## Player behavior

- **256 — bridge elemental finale with Tweaks Anthology `3500`.** Tweaks
  Anthology's "Summoned Creatures Clear Fog of War" (`cdtweaks` 3500) gives every
  summoned creature a permanent self-cast of `CDTFOW`. 256 refused that effect as
  an unreviewed donor effect and stopped the installation: on EET at the summoned
  fire elemental `BDELFIRM`, on BG:EE+SoD also at the `SUMELEAR` fallback.
  `CDTFOW` clears the fog of war only for allies, so the hostile bridge
  elementals now leave exactly that effect behind; their donors stay unchanged.
  Any other shape of it, and every other unknown effect, still stops the
  installation before anything is written
  ([#31](https://github.com/Chrizhermann/chriz-sod-rebalance/issues/31)).
- Nothing else changes. Encounter roster, difficulty tiers, timer and XP of 256
  are the same as in v0.6.14.

## Install timing and limits

- Unchanged from v0.6.14: install 256 before first entering BD2000, either alone
  or appended after an existing 255.
- An existing 256 installation needs no update; it could only have installed
  without Tweaks Anthology `3500`.

## Verification boundary

- Regression fixtures with the game's table layout (effects before items and
  slots) in both effect formats: both `BDELFIRM` clones drop the fog effect (also
  with an upper-case resource) and keep the remaining effects byte-exact, the
  BG:EE+SoD `SUMELEAR` fallback drops it too, and every single-field drift or a
  different resource still stops with nothing written.
- Lab on a disposable EET 2.7.3.0 copy of the full Chriz Easy BG Recommended
  stack with `3500` on, which had stopped at 256 with v0.6.13: the fixed library
  installed 256 and the remaining tail (260 through 910) without warnings.
  `BDELFIRM` keeps its `CDTFOW` effect, and no 256 clone carries it. No other
  component clones a summoned creature.
- Not covered: a playthrough of the bridge encounter, and a complete Recommended
  collection install with `3500` on from this release.
- Local run on the release source (Windows, WeiDU 249): 393 regression tests pass
  (8 skipped where a captured fixture or the development game copy is not
  available), as do the 41 research-script tests and the ending self-test's 14
  checks. WeiDU 249 parses the TP2 and all 73 TPA libraries.
