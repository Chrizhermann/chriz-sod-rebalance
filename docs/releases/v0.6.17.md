# v0.6.17 — Every component writes its decided result

Released November 8, 2026, on top of v0.6.16. The installer still exposes
**49 declarations in seven groups**.

## Player behavior

- **What the game files hold no longer stops a component.** Before this release,
  many components compared the resources they change with the vanilla or
  expected shape and stopped the installation, printed a warning or skipped
  themselves when another mod or a hand edit had changed them. Now each component
  writes the result it decided: edited values are overwritten, missing owned
  dialogue states are recreated, and its script blocks are replaced or added
  whole (`lib/overwrite.tpa`). Other mods' versions of the same resources no
  longer matter for the outcome.
- **The mandatory components 177, 198 and 285** follow the same rule.
- What is still required: the game type, and the components a component builds
  on.

## Install timing and limits

- No component, order or default changed. Install it at the same place as
  v0.6.16.
- With unchanged game files the result is the same as before. Some bytes differ
  without changing the game: 2DA spacing, the layout of compiled script blocks
  and unused private spellbook bytes.

## Verification boundary

- Code audit: 848 findings, 776 changed and 72 kept (required targets, game
  type, one feature requirement, caller errors, offline checks). Of 432 explicit
  stop and warning statements, 2 remain, both checks of our own calling code.
- Automated: 537 unit tests and 40 research-script tests pass on CI (Linux,
  WeiDU 249). This release also fixes four test fixtures that only failed on a
  case-sensitive file system; the mod itself did not change for that.
- Lab: a full Chriz Easy BG Recommended install on BG2:EE 2.7.3.0 with EET on
  November 8, 2026, using this code (commit `f8c337a`: the same component code
  as this release; only the version and the texts differ): 466 of 466 components installed, no
  errors, no new warnings from SoD Remix. The game started and loaded a save.
- Not covered: playing the changed scenes, and installs on top of other mods'
  edited versions of SoD resources beyond the test fixtures.
